# Changelog

## 0.1.2

Fixed a crash when the drum filter picker previewed Septet. Tested on hardware with Trine RC4 on Drumline and a second drum machine, including playback and switching away. This release targets Open-XY API 1.17.

## 0.1.0

First public release. Seven-band stereo EQ on the OP-XY instrument track sum, with Series / Parallel, Correction Solo and Mid / Side routing. M3 shows the response, band gains and K4 sweep. K2 switches banks and K3 resets all seven gains to 0 dB.
